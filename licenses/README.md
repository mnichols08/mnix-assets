# Component licenses and provenance

Every manifest record retains the original source URL, license source, rights status and legal notes. Engine and game-data terms may differ. Preserve original package notices and publish corresponding source where required.

The existing collection was explicitly requested to remain available by the repository owner. Unverified shareware/demo and proprietary guest packages remain marked `redistributable: false` with an explicit owner-requested-existing-collection authorization and date. This records the owner's instruction; it is not independent verification of redistribution permission.

No ownership is claimed. Educational purpose, age, freeware/shareware labels or availability on mirrors do not establish rights. New packages require individual review. Do not add retail substitutions, cracks, keys, serials, or registered game episodes.
